# train-oomawari

JR東日本・東京近郊区間の大回り経路探索。

## 現在の仕様

- 入力: 出発駅・到着駅
- 出力: その2駅を結ぶ「同じ駅を2回通らない」経路のうち、総営業キロが最大のもの
- データ: `data/tokyo_near_zone.csv`（現在は初期取得処理を用意済み）
- 実行時に外部APIは使用しない
- CLIで利用可能。将来、駅名プルダウンUIに置き換える

JR東日本の規則では、大都市近郊区間内相互発着の普通乗車券について、区間内の他経路を選択して乗車できます。JR東日本の案内でも、特定区間について「後戻りしたり再度同じ駅を通らない」ことが条件として示されています。

## 実行

```bash
python oomawari.py 東京 新宿
```

初期セットアップでは固定したデータソースから `data/tokyo_near_zone.csv` を取得してリポジトリへ保存する構成です。取得後の実行時には外部通信を行いません。

## データ

現在の初期データセットは、東京近郊区間の駅間・営業キロを4列CSV
(`駅1,駅2,営業キロ,路線`) として公開している資料を取得したものです。
更新時にはJR東日本の現行営業規則と照合してください。

## 注意

これは経路探索プログラムです。乗車可否・運賃の最終判断はJR東日本の現行規則・駅係員の案内を優先します。
